Calculadora de IVA

Añade el IVA a una base o extráelo de un precio final para conocer cada parte del importe.

Puedes introducir cualquier porcentaje. Verifica qué tipo corresponde al producto o servicio.

Dos operaciones diferentes

Para añadir IVA se multiplica la base por 1 más el tipo. Para quitarlo no basta con restar ese porcentaje: hay que dividir el total.

Ejemplo: quitar un 21% a 121 € da una base de 100 €, no 95,59 €.

Cómo añadir o quitar el IVA

Para añadirlo: total = base × (1 + tipo). Para extraerlo: base = total ÷ (1 + tipo). La cuota es la diferencia entre total y base.

Redondeos

La herramienta muestra importes con dos decimales. En facturación real pueden existir reglas de redondeo por línea o por total.

Límite importante

Esta calculadora realiza la operación matemática, pero no decide el tipo fiscal aplicable ni sustituye documentación tributaria.

Metodología revisada: 23 de septiembre de 2026.

Dudas habituales

Preguntas frecuentes

¿Cómo se quita el IVA de un precio?

Se divide el total entre uno más el tipo expresado en decimal.

¿Qué tipo debo elegir?

El que corresponda legalmente al producto o servicio; la herramienta no determina su clasificación fiscal.
